# Event Manager

## 📝 Descripción

Aplicación web para la gestión de eventos y reservas, desarrollada como proyecto práctico de aprendizaje de arquitectura *cloud* y despliegue en AWS.

El objetivo es construir una aplicación funcional y evolucionarla progresivamente desde un entorno local hasta una infraestructura desplegada, automatizada y monitorizada en AWS.

---

## 🎯 Objetivos de aprendizaje

- Diseñar e implementar una API REST con Java y Spring Boot.
- Desarrollar una interfaz web con Angular.
- Gestionar persistencia con PostgreSQL.
- Aprender los fundamentos de arquitectura y seguridad de AWS.
- Definir infraestructura mediante Terraform.
- Contenerizar la aplicación con Docker.
- Automatizar pruebas y despliegues mediante GitHub Actions.
- Incorporar monitorización y control de costes.

---

## 🏗️ Arquitectura prevista

- **Frontend:** Angular
- **Backend:** Java y Spring Boot
- **Base de datos:** PostgreSQL
- **Infraestructura:** AWS, gestionada mediante Terraform
- **Contenedores:** Docker
- **CI/CD:** GitHub Actions

> *Nota: La arquitectura definitiva se concretará durante el desarrollo. Las tecnologías indicadas son objetivos iniciales, no componentes ya implementados.*
